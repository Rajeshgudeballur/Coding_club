# GMU Coding Club Website

This is the official website for the GMU Coding Club, built using:

- Vite
- React (TypeScript)
- Tailwind CSS
- shadcn/ui

## 🚀 Live Website

Hosted on GitHub Pages:  
https://rajeshgudeballur.github.io/Coding_club/

```bash
